# Paper owl

Original mascot created for this project using the built-in imagegen tool, 2026-09-05. The working product name is unchanged. The master is a 1254 × 1254 PNG with genuine alpha transparency; it is raster artwork, not an editable vector drawing.

- `paper-owl-master.png`: original generated artwork, retained unchanged.
- `paper-owl.png`: Tauri's 128px icon export, used in the workbench and favicon.
- Native ICO/ICNS variants live in `src-tauri/icons/`; the launcher uses `desktop-ui/paper-owl.png`.

Final generation prompt:

> Use case: logo-brand. Create one final premium desktop application mascot icon for a scholarly research workbench. An original small owl sculpted from folded ivory paper: compact rounded silhouette, two pointed folded paper ears, two symmetrical large ink-black almond eye shapes with ivory pupils, subtle center fold forming a tiny beak, folded wings suggesting book pages. Calm, intelligent, endearing but sophisticated, collectible design object quality. Minimal geometric design with extremely clean edges, broad simple shapes that remain readable at 24px, delicate dimensional paper shading, restrained warm ivory and charcoal palette with tiny muted copper detail. Front facing centered owl occupies 82% of canvas. Genuine transparent background, no badge tile, no scene, no typography, no lettering, no watermark, no extra objects, no green, no fuzzy haze, no photorealistic feathers. Square high resolution PNG suitable as master artwork for Windows ICO and macOS ICNS. The owl itself should have a thin dark silhouette edge for visibility on light or dark backgrounds.
