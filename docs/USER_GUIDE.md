# Paperweave 使用指南

## 第一次

把 [仓库地址](https://github.com/shanyuzhe/paperweave) 发给 Agent，说：“帮我安装并启动，按 INSTALL.md 操作。”

安装完成后，打开它给你的网页地址，直接在页面里的终端和 Agent 对话。你不用自己处理依赖或 MCP 配置。

## 读论文

告诉 Agent 你想研究什么，它会把论文和摘要放进看板。点击一篇论文，查看摘要，或进入“论文精读”看 PDF。

遇到不懂的地方，在页面划选原文、写下问题，然后在下方终端里说：“看看当前问题，给我讲明白。”讨论清楚后，再说：“把这段理解存成笔记。”

## 记笔记

可以让 Agent 记录，也可以在“笔记与讨论”中自己写。已有 Obsidian vault 的话，把路径告诉安装 Agent，让它连接；暂时没有也可以直接用。

笔记和草稿编辑后记得点击“保存”。

## 画图与写作

在“科研图件”中查看素材、模型图和结果图。需要在 PPT 中精修时，让 Agent 导出可编辑 PPTX，再沿用你原来的绘图方式。

在“论文写作”中新建草稿，和 Agent 一起组织、修改章节。需要 PDF 时点击“编译 PDF”；如果缺少编译工具，告诉 Agent：“帮我补齐写作依赖。”

## 下次继续

对 Agent 说：“启动 Paperweave，继续上次的研究空间。”之前的论文、脉络、笔记和草稿都会保留。

也可以运行 `npm start`，页面会自动打开。终端上沿可以拖动，右上角可以分屏、放大和切换配色；奶油黄、本地配色和深色都可选。

收起终端面板会保留任务；关闭网页会结束网页内的终端会话。长实验可以继续放在你原来的外部终端中。

如果遇到问题，把页面报错原文发给 Agent，说：“按仓库的故障修复手册处理。”
