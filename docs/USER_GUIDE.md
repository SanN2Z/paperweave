# 扇子 使用指南

## 第一次

Windows 可以直接[安装桌面预览版](https://github.com/SanN2Z/paperweave/releases/tag/v0.2.0-beta.1)，打开研究目录，再把“连接 Agent”里的连接信息发给当前 CLI。应用依赖已经包含在安装包里。

把 [仓库地址](https://github.com/SanN2Z/paperweave) 发给 Agent，说：“帮我安装并启动，按 INSTALL.md 操作。”

安装完成后，打开它给你的网页地址，直接在页面里的终端和 Agent 对话。你不用自己处理依赖或 MCP 配置。

## 读论文

告诉 Agent 你想研究什么，它会把论文和摘要放进看板。点击一篇论文，查看摘要，或进入“论文精读”看 PDF。

PDF 可以一直向下滚动阅读。划选原文后点“让 Agent 解读”，问题会交给右侧 CLI；也可以直接在 CLI 提问。讨论清楚后，说：“把这段理解存成笔记。”选区小工具点别处或按 Esc 即可关闭。

## 记笔记

打开“研究笔记”，点一条笔记即占据左侧阅读区。直接点击排版后的正文就能编辑；需要时切换“Markdown 源码”。点“返回笔记列表”回到目录。已有 Obsidian vault 的话，把路径告诉安装 Agent；两边编辑的是同一份 Markdown。

笔记和草稿编辑后记得点击“保存”。

## 画图与写作

在“科研图件”的模板库选一个模板，点“用这个模板绘图”，写下修改要求。Agent 会获得单独的工作副本，修改矢量组件并更新预览；结果在“我的图件”。原模板保留。若终端当前是普通 Shell，要求只会填入，不会执行；先进入 Codex / Claude 对话再发送。

在“论文写作”中新建草稿，和 Agent 一起组织、修改章节。需要 PDF 时点击“编译 PDF”；如果缺少编译工具，告诉 Agent：“帮我补齐写作依赖。”

“专注写作”可展开左侧编辑区，章节目录按需打开。Markdown 草稿的预览也支持直接编辑。

画布上的论文可以自由拖动；按 Shift 选多张一起移动，从卡片连接点拖到另一篇论文可建立关系。位置会保存。

## 下次继续

桌面版直接点快捷方式。关闭主窗口会收进托盘，终端继续运行；需要彻底退出时，从托盘选择“退出…”。右上角“会话监控”可打开独立浮窗，支持置顶、折叠和返回工作台，目前读取 Claude 的会话状态。

对 Agent 说：“启动扇子，继续上次的研究空间。”之前的论文、脉络、笔记和草稿都会保留。

也可以运行 `npm start`，页面会自动打开。左侧像浏览器一样切换研究标签页，点“+”打开页面；右侧一直保留 CLI。中间的分隔线可以左右拖动，右上角可以分屏、放大和切换配色。

已有实验目录时，告诉 Agent：“把工作台接到这个目录，保留当前会话。”它会在项目内准备空间；长实验继续留在原来的 CLI。

在任何目录，只要当前 Agent 能调用已连接的 扇子 MCP，就能操作对应的研究空间。仅仅切换终端目录不会切换研究空间；换项目时说：“接入这个项目”，让 Agent 确认连接到了正确的空间。

终端中 `Ctrl+Shift+D` 分屏，`Ctrl+Shift+T` 新建，`Ctrl+Shift+W` 关闭当前终端，`Alt+方向键` 切换面板。终端工具栏的快捷键按钮可查看完整列表。关闭面板会结束该 Shell 的进程。

收起终端面板会保留任务；关闭网页会结束网页内的终端会话。长实验可以继续放在你原来的外部终端中。

粘贴文字时，点击终端后按 `Ctrl+V`（Mac 用 `⌘V`），也可以点击终端里的“粘贴”。PDF 报错时先重试；仍然失败，把“错误详情”里的文字发给 Agent。

截图也可以直接粘贴到终端：图片会保存在当前空间，图片路径会填入 CLI，支持识别路径的 CLI 会显示图片附件。接着输入问题再发送即可。支持 PNG、JPEG、WebP、GIF，单张不超过 20 MB。

如果遇到问题，把页面报错原文发给 Agent，说：“按仓库的故障修复手册处理。”
